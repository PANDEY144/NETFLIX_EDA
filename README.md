# 🎬 Netflix Exploratory Data Analysis (EDA)

📌 Overview

This project dives deep into the Netflix dataset to uncover trends, patterns, and insights about movies 🎥 and TV shows 📺 available on the platform.
Using Python (Pandas, Matplotlib, Seaborn, Scikit-learn), we perform exploratory data analysis to answer questions such as:

Which countries contribute the most content? 🌍

Do movies dominate Netflix or TV shows? 🎥 vs 📺

What genres are most popular? 🎭

How has content evolved over the years? 📆

Which ratings are most common? 🔖

# 📊 Dataset

Total Records: 8,790

Columns: 10 (show_id, type, title, director, country, release_year, rating, duration, listed_in, date_added)

Movies: 6,126 (≈70%)

TV Shows: 2,664 (≈30%)

Release Years: 1925 → 2021

# 🚀 Key Insights

United States 🇺🇸 dominates Netflix content, followed by India 🇮🇳 and the United Kingdom 🇬🇧.

Movies make up ~70% of the catalog, while TV Shows account for 30%.

Content production surged after 2010, peaking between 2017–2019.

Top Genres: International Movies 🌎, Dramas 🎭, Comedies 😂, Documentaries 📚, Action & Adventure 💥.

Most Common Rating: TV-MA (Mature Audience).

# 📈 Visualizations

📊 Bar Charts: Country distribution, genre frequency, ratings.

📆 Histograms: Release years & movie durations.

📦 Boxplots: Movie duration vs rating.

🔥 Heatmaps: Feature correlations.

🔄 Pairplots: Variable relationships.

# 🛠️ Tech Stack

Python 3 🐍

Pandas – Data manipulation

Matplotlib & Seaborn – Data visualization 🎨

Scikit-learn – Encoding & preprocessing

# 🏁 Conclusion

Netflix’s strategy emphasizes:
✔️ A movie-heavy catalog with growing TV show investments.
✔️ Focus on international & diverse genres.
✔️ Strong adult-oriented content base.
✔️ Rapid growth post-2010, shaping modern streaming trends.
